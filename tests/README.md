# Software tests

These files are for developers checking firmware changes. They are not programs to install on your clock.

For normal setup and operation, use [the user guide](../docs/USER_GUIDE.md). Developers should follow [the supported test commands](../docs/development/TESTING.md).

Some test modules retain names from earlier development stages because the current suite inherits their models. Use the current suite's documented entry point rather than running every old file separately. No old firmware binaries are included here.
