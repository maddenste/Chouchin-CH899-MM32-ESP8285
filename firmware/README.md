# Firmware source

This folder is for developers. To install and use a prepared release, follow [the installation guide](../docs/GETTING_STARTED.md); you should not need to edit these files.

- `mm32/` contains the movement controller application and programming project.
- `esp/` contains the Wi-Fi/settings application and its test fixtures.

Build instructions, tests and protocol details are in [the developer guide](../docs/development/README.md). Generated firmware files are not committed to Git. Firmware downloads will be supplied separately when a tested release is available.
