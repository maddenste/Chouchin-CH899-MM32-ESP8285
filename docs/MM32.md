# Install the MM32 movement firmware

Use the **MM32 RC6BC** HEX and programming project from [downloads](DOWNLOADS.md).

This step updates the chip that controls the hands. You also need to install the accompanying [ESP Wi-Fi firmware](FLASHING.md).

## What you need

- A Windows PC with **Keil µVision**.
- The **MindMotion.MM32SPIN0x_DFP 1.0.8** device pack, which supplies the tested MM32SPIN05PF programming support.
- A compatible **CMSIS-DAP SWD programmer**.
- The matching MM32 HEX file and programming project.
- A stable regulated 3.3 V board supply, with the batteries removed.

These tools are obtained separately. You do not need to compile firmware to use a prepared release; [building from source](development/BUILD.md) is a separate developer task.

Download µVision as part of **MDK-Arm** from [Keil's product downloads](https://www.keil.com/download/product/). The tested device pack is available on [Keil's MM32SPIN0x pack page](https://www.keil.arm.com/packs/mm32spin0x_dfp-mindmotion/boards/); choose **MindMotion.MM32SPIN0x_DFP.1.0.8.pack**, not a different MM32 family.

## 1. Connect the programmer

Remove clock power first. Use the [MM32 pad photograph](HARDWARE.md#mm32-pads) and check the labels on your board.

| Programmer | Clock pad |
| --- | --- |
| GND | GND |
| SWDIO | DIO |
| SWCLK | CLK |

Use short leads. Power the clock separately at the verified battery terminals with regulated **3.3 V**. Do not connect a programmer power output at the same time.

If your probe needs a voltage-reference input, follow its own wiring instructions. A voltage-sense input and a power output are not the same thing. Do not guess the reset or power wiring from another programmer's pinout.

## 2. Open the programming project

Open the MM32 programming project supplied with the firmware. The release's project is named `MM32SPIN05_DeadlineGuard_RC6BC_Programmer.uvprojx`; its firmware file goes in the project's `build` folder.

In µVision, check:

- Target device: **MM32SPIN05PF**.
- Programmer: the **CMSIS-DAP probe actually connected**. Select your unit in Debug → Settings before programming; the supplied project is not bound to the developer's individual probe.
- Interface: **SWD**.
- Flash programming support: the algorithm from the MM32 device pack.

Do not choose ULINK unless you are actually using a ULINK programmer.

## 3. Program the clock

1. Check that the HEX file matches the version you intended to install. Compare its checksum with the release's checksum list.
2. Apply the regulated board power.
3. Select **Flash → Download**.
4. Wait for successful programming **and verification**.

If the target is not found or verification fails, stop and check the connections, supply and tool settings. Do not select a similar-looking chip or change protection settings to force it through.

Use **Flash → Download**, not the Debug command, to install the prepared file. The supplied project does not automatically flash when entering debug, but a debug session can still stop/reset the clock and affect its movement.

## 4. Finish

Remove power and disconnect the programmer's driven signals. Continue with the [ESP guide](FLASHING.md) if needed, then restart normally and follow [setup](USER_GUIDE.md).

Keep any verified original backups you already have. Do not erase the whole chip or alter readout protection as a routine troubleshooting step.
