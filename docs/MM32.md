# Install the movement firmware

This step programs the MM32 chip that controls the hands. Start with [the installation overview](GETTING_STARTED.md) if you have not already checked your board and gathered the equipment.

> [!WARNING]
> **Install at your own risk.** The factory MM32 firmware is read-protected and cannot be read out for a backup. Once overwritten, it cannot be recovered from the chip. This replacement was built from scratch. Testing is ongoing; please [report any bugs](https://github.com/maddenste/Chouchin-CH899-MM32-ESP8285/issues).

## What you need

- The extracted [WiFi Clock v1.5 installation package](DOWNLOADS.md).
- A Windows PC with **Keil µVision** and **MindMotion.MM32SPIN0x_DFP 1.0.8**.
- A **CMSIS-DAP / DAPLink programmer** — [the hardware listing used for this project](https://www.ebay.co.uk/itm/254327616482).
- A regulated **3.3 V supply**, with the clock's batteries removed.

Download µVision as part of [Keil MDK-Arm](https://www.keil.com/download/product/). Install **MindMotion.MM32SPIN0x_DFP.1.0.8.pack** from [Keil's MM32SPIN0x pack page](https://www.keil.arm.com/packs/mm32spin0x_dfp-mindmotion/boards/).

## 1. Connect the programmer

With clock power removed, connect the programmer to the [labelled MM32 pads](HARDWARE.md#mm32-pads):

| Programmer | Clock pad |
| --- | --- |
| GND | GND |
| SWDIO (also labelled TMS/IO) | DIO |
| SWCLK (also labelled TCK/CK) | CLK |

Use short leads. Connect the regulated **3.3 V** supply to the clock's battery terminals, checking polarity. Leave power off for now. Do not connect a programmer power output alongside the external supply.

If your programmer requires a voltage-reference input, follow its own instructions. A voltage-reference input is not a power output.

## 2. Open the installer

1. Extract the complete WiFi Clock ZIP to a folder on your PC.
2. Open **Install-MM32.uvprojx** in Keil µVision.
3. In **Options for Target → Debug**, select **CMSIS-DAP Debugger**.
4. Open **Settings**, select your connected programmer and choose **SWD**.

The project already includes and selects the movement firmware. Leave the extracted folder structure intact; no compiling or file relocation is required.

Check that the target device is **MM32SPIN05PF** and the flash algorithm is **MM32SPIN05_32** from the installed device pack. Do not select ULINK unless that is the programmer you actually own.

## 3. Program the movement controller

1. Apply the regulated 3.3 V power.
2. Select **Flash → Download**.
3. Wait for programming and verification to finish successfully.

Look for **Programming Done** and **Verify OK** in the output pane before continuing.

Use **Flash → Download**, not the Debug command. A debug session can stop or reset the clock and affect movement.

If the programmer cannot find the chip or verification fails, stop and check the wiring, power, selected programmer and device pack. See [programming help](TROUBLESHOOTING.md#a-programmer-will-not-connect).

## 4. Continue with the Wi-Fi firmware

Remove power and disconnect the SWD programmer's driven signals. Follow [the ESP installation guide](FLASHING.md) to program the Wi-Fi chip from the same package.

Once both chips are programmed, remove the temporary programming connections and follow [first-time setup](GETTING_STARTED.md#4-start-the-clock).
